Arduino Control Studies

I worked through several small builds using analog input, adjustable blink rates, PWM fading, and a timed traffic light. When something failed, I stopped changing everything at once and checked the wiring and code one step at a time.

The brief

I wanted to understand how an Arduino turns a sensor reading or timing instruction into something I could actually see happen.

How I approached it

  1. 01

    I wired each circuit and used a minimal sketch to confirm that the output worked.

  2. 02

    I mapped analog input values to changes in timing and brightness.

  3. 03

    I built a traffic-light sequence with several outputs and deliberate state changes.

  4. 04

    I debugged the wiring and code by changing one variable at a time.

From the build

What worked

  • Analog input
  • PWM fading
  • Timed multi-LED sequence

What I learned

These exercises made programming feel less abstract. I could watch a sensor value become a decision in the code and then turn into light or movement in front of me.

If I built it again

I would combine sensing and state logic in a small assistive-device prototype and write down test cases before changing the code.
